SatSim Documentation
====================

Simulation for developing understanding of satellite RPO and attitude determination and control.

Structure
---------

A simple model-view-controller architecture is used to separate the data display from the core simulation.

Model
^^^^^

Calculating location along the orbit, orbit transfer methods, and other algorithms.


View
^^^^

View the simulation or a subset, delta-v over a period of time, etc.


Controller
^^^^^^^^^^

Load and save config, set orbit, run simulation.
